# PicklePilot

**Built for Captains. Powered by AI.**

PicklePilot is an interclub pickleball lineup assistant designed to help captains build competitive, rule-compliant lineups faster.

## MVP status

The first English dashboard includes:

- upcoming match and player availability
- season performance summary
- AI lineup recommendation preview
- responsive desktop and mobile layouts

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
